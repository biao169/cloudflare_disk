# 文件与分享功能

## 文件管理

- `/files` 为所有具有权限的空间的文件管理器，`/personal` 只展示个人空间但与 `/files` 共享目录树、文件列表、网格、搜索、排序、上传和操作组件；`/spaces` 管理空间与成员。
- 桌面端左侧为按需展开的多级文件夹树，右侧为所选文件夹的文件与子文件夹。双击打开文件夹，移动端保留打开按钮。
- 目录支持重命名、移动、批量复制、批量删除、收藏、分页和访问控制。文件上传后进入 ready 状态才可正常访问。
- 大文件使用 R2 Multipart 分片与恢复，上传会话、配额预留与已占用空间记录在 D1。不要直接在 R2 修改对象 Key，否则 D1 元数据会失效。
- 浏览器支持预览常见图片、PDF 和部分视频格式；其他格式走下载。静态资源由 `public/` 提供。

## 分享与公开链接

- 文件和文件夹可创建临时分享、密码分享页、限时/限次分享、公开发布；已有分享可查看、编辑和撤销。
- R2 私有存储桶 `PRIVATE_BUCKET` 不应开启公开访问。公开副本由 `PUBLIC_BUCKET` 管理，并可选配置 CDN 域名。
- `/s/*` 为 R2 分享展示页，`/t/*` 临时链接，`/p/*` 公开副本，`/r/*` 永久入口。新文件版本可保留原逻辑文件 ID 和公开入口。
- OneDrive 公开文件使用 `/s/odf_*`（展示）、`/r/odf_*`（下载），合集使用 `/s/odg_*`。`odf` 固定的是 CloudDrive 入口，微软临时下载地址会过期。
- 分享密码、到期、下载/浏览次数、管理员暂停/撤销均由 Worker 检查；对合集内文件还会验证父级权限。302 跳转只能统计下载跳转，不保证微软文件实际传输完成。
- 已经向浏览器发放的短期微软预授权 URL 不能被本站立即召回。严格可撤销授权应考虑受控流式下载及微软侧撤销。

## 空间与成员

- 每位用户具有个人空间；团队空间支持管理员、编辑者和查看者权限。文件夹可设置额外 ACL，文件操作与 API 均在后端执行权限检查。
- 禁止以普通用户身份直接访问管理员存储、OneDrive 私人授权文件或越权获取 R2 对象。

## 资源、版本和恢复

- 历史版本、在线文本编辑、回收站与恢复、容量/配额、定期清理、同步异常及备份登记均通过后台管理。
- 数据库保存 UTC 时间，浏览器自动按用户本地时区展示；不要手工将 UTC 数据改成北京时间。
- R2 和 D1 必须配套备份：D1 只有元数据，单独恢复 D1 不会自动恢复文件内容。
