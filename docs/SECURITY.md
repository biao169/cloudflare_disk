# 安全规范与上线阻断项（Stage 12）

## 已实现

- D1 会话 Cookie (`HttpOnly`, `SameSite=Lax`, HTTPS `Secure`)、服务器端过期/注销、登录失败计数。
- 写操作检查同源 Origin/Referer；管理员及目录权限必须由 Worker 重新核验。
- 分享 Token 随机生成，D1 仅保存哈希；密码使用 PBKDF2-SHA256，不在分享 API 返回摘要；临时分享和密码页不公开原始对象。
- Worker 返回的管理页/登录页/分享页含 CSP、`X-Frame-Options: DENY`、`no-store`、`Referrer-Policy: no-referrer`。
- 预览 MIME 白名单以及前 32 字节的常用魔数校验，预览接口可读取范围但不会公开私有存储 Bucket。
- 文件/目录跨空间的权限校验；删除后撤销私密分享、尝试删除公开副本。
- 存储物理删除使用 D1 清理队列；R2 故障后定时重试。永久公开副本计入应用空间上限（0011 迁移补计历史 ready 发布记录）。

## 上线阻断项（需要实测/评估）

1. **PBKDF2 CPU 配额**：密码派生采用 100,000 次迭代。Cloudflare Free Worker 单次 10ms CPU 限制能否支持登录、设置密码和密码分享，尚未经线上真实测量；如果被阻断，必须调整认证架构或计划后才能投入公网。
2. **未进行真实 Windows/Miniflare/R2/D1 浏览器回归**：Node `node:sqlite`、MemoryR2 与 Cloudflare 原生 Binding 行为不是完全相同的实现。不能视为线上验证。
3. **文件内容安全**：魔数校验不等于病毒扫描、图片解码验证或文件转换，复杂格式可能含恶意内容。建议禁用所有 HTML/SVG 的同源内联预览，必要时将预览迁到隔离域名。
4. **跨服务原子性**：D1+R2 无跨系统事务。普通上传/发布失败时会执行尽力回滚；在极端双重故障下仍可能出现孤立对象，管理员必须通过 R2 对象盘点和 D1 对账修复。
5. **Multipart 失败状态**：`verifying`/`failed` 且已在 R2 完成的会话不会被自动丢弃（避免数据丢失），需要管理员核对真实对象、会话和预留量后处理。
6. **大规模目录**：递归查询有深度/分批限制；同时删除非常大的共享目录与权限变更需要额外的压力、并发测试。
7. **公网直链**：R2 公开副本必须独立于私有桶；撤销/删除不能保证清理所有 CDN 和浏览器缓存。不要公开涉及隐私的文件。
8. **多次下载限制**：Range 分段访问不能无损计入“一次完整下载”；若使用 `max_downloads` 严格限制，当前拒绝 Range 下载以防止绕过次数。已下载的数据无法收回。
9. **超额计费**：8 GiB 应用软上限不是 Cloudflare 硬账单保护，R2 免费额度为 GB-month；操作次数、临时分片、应用之外的数据也可能计费。

## 生产安全清单

- [ ] R2 私有 Bucket 未绑定任何公开域名；`r2.dev` 在私有桶关闭。
- [ ] `BOOTSTRAP_TOKEN` 只作为 Secret 储存，管理员初始化成功后轮换/删除。
- [ ] D1 远程数据库 ID 已替换示例值，并完成备份。
- [ ] 无真实密码/卡号/用户文件出现在 git/ZIP/日志。
- [ ] 所有 write API 由认证、CSRF 与 ACL 覆盖；HEAD、Range 未绕过。
- [ ] HTTPS 域名证书可用，不能通过生产 HTTP 传输 cookie。
- [ ] 对外公布之前，完成 Windows 及线上 Free CPU 额度验收。
