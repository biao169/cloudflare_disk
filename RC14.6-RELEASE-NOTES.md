# CloudDrive RC14.6 release notes

- Added opt-in public download routing for existing OneDrive fixed-entry URLs.
- Added anonymous independent compatibility probe: `POST /api/v1/tools/onedrive/public-check`.
- Added `PATCH /api/v1/tools/onedrive/links/{id}` to toggle `public_direct` / `source_page_redirect` for the owner.
- Browser tool now provides **验证公开文件直链** and link mode controls.
- Requires D1 migration `0026_rc14_6_onedrive_public_delivery.sql`.
- Fail-closed: no administrative Graph token or private Graph preauthorized download URL is ever used by an anonymous download request.
- The unauthenticated `api.onedrive.com` probe is legacy/best-effort; no guarantees for OneDrive Business and not verified against live accounts.
- Existing `/r/od_*` remain source-page redirects unless owners explicitly opt in. On failed probe opt-in links fall back to share pages.
- `npm run build` local validation: 101 unit tests, 107 integration tests passed, migration and JS syntax checks passed.

Read `docs/RC14_6_ONEDRIVE_PUBLIC_DELIVERY.md` before deploying.
